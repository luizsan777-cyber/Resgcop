# RegsCo

Aplicativo Android de compras domésticas. Esta é uma versão inicial para validar a compilação e instalação do APK; **não é o produto completo**.

## Compilação

Abra **Actions → RegsCo APK → Run workflow** ou faça um push na branch main. Após o sucesso, baixe o artefato **RegsCo-debug-apk** e extraia `app-debug.apk`.

O APK debug é apenas para testes. A integração com preços online, OCR e recursos avançados ainda não está concluída.
